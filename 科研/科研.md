这篇论文通过整合 BEHAVE、OMOMO 等 7 个来源，构建了目前规模最大的 3D 人机交互（HOI）基准数据集 **InterAct**（21.81 小时）及其增强版 **InterAct-X**（30.70 小时），并利用 GPT-4 补充了精细的文本标注 。其核心做法是开发了一套统一的优化框架，首先修正原始数据中常见的穿模、接触漂浮等物理伪影，随后基于“接触不变性”原理生成合成数据以扩充规模，并采用基于人体表面 Marker 的多任务扩散模型来统一解决文本驱动生成、交互预测、动作模拟等六大类任务 。实验对比的 Baseline 包括 **HOI-Diff**（文本/动作生成）、**OMOMO**（人体生成）和 **InterDiff**（动作预测）等 。复现难度方面，虽然项目代码和数据已在 GitHub 开源 ，但时间成本和算力门槛较高，例如训练单个生成任务通常需要在 NVIDIA A40 级别 GPU 上运行约 8 天时间 。



**HOI-Diff** 论文采用模块化设计，将复杂的人机交互生成分解为初步运动生成、接触点估计与交互修正三个步骤：首先利用带有跨注意力通信机制的**双分支扩散模型 (DBDM)** 分别生成人体与物体的粗略运动 ；同步使用**接触预测扩散模型 (APDM)** 根据文本和物体几何独立估计关键关节的接触区域 ；最后通过分类器引导（Classifier-guidance）将预测的接触点融入扩散步中进行实时修正，以解决物体漂浮或穿模问题 。该研究主要在手动补充了文本标注的 **BEHAVE** 数据集以及 **OMOMO** 数据集上进行验证 ，对比的 Baseline 包括 **MDM**（及其变体 MDM*）、**PriorMDM*** 以及增加文本控制的 **InterDiff** 。复现难度适中，作者已公开代码与标注数据 ，但由于涉及多个扩散分支的联合优化以及人体运动先验的微调 ，对算力支持和多阶段训练的逻辑衔接有一定要求。
